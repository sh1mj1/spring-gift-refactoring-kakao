# 주문 트랜잭션과 카카오 알림

## 현재 작동
포인트 차감이 실패하면 재고만 줄어든다. 카카오 발송 실패나 토큰 누락에도 주문은 성공한다.

## 목표 작동
재고·포인트·주문을 한 트랜잭션에 넣고 발송 전에 flush한다. 토큰이 없으면 발송 없이 403, 발송 실패 시 최초 호출과 추가 5회 재시도 후 403을 반환한다. 두 경우 모두 저장 상태를 보존한다. 카카오 알림 계약상 발송 성공이 주문 성공의 조건이다.

## 유지할 작동과 검증
- 성공 201, Location, 응답 필드와 저장 결과는 주문 성공 인수 테스트로 검증한다.
- 재고·포인트 부족 500과 없는 옵션 404는 각각 상태와 저장 결과를 재조회한다.
- 기존 주문 목록과 상세 URL 404는 기존 인수 테스트로 검증한다.

# 주문 금액 계산 책임 이동

## 현재 작동

주문 서비스와 카카오 클라이언트가 각각 현재 상품 단가와 주문 수량을 곱한다.

## 변경할 책임

`Order.totalPrice()`가 옵션의 상품 단가와 주문 수량을 곱한다. 서비스는 이를 포인트 차감에 사용하고 카카오 클라이언트는 알림의 금액 표시에 사용한다.

## 유지할 작동과 검증

- 기존 단가와 수량에 따른 재고·포인트 차감과 주문 저장은 `OrderServiceTest`로 검증한다.
- 카카오 발송 요청의 금액 형식과 문구는 `KakaoMessageClientTest`로 검증한다.
- 주문 응답, 롤백, 위시 삭제와 발송 재시도는 기존 `OrderingAcceptanceTest`로 검증한다.
- 상품 단가를 계산 시점에 읽고 기존 정수 곱셈과 DB 매핑을 유지한다.

# 3. 용어 사전

| 한글명 | 영문명 | 설명 |
| --- | --- | --- |
| 회원 | Member | 이 프로젝트에서 관리하는 `Member`. 서비스 내 주문, 위시리스트, 포인트 잔액이 이 회원에 연결된다. |
| 카카오 계정 | Kakao Account | 카카오에서 관리하는 로그인 계정. 서비스는 카카오 로그인 과정에서 이 계정의 이메일을 받아 회원을 찾는다. |
| 관리자 | Admin | /admin 화면을 쓰는 사람. ⚠ admin@example.com은 이름만 관리자인 일반 회원 |
| 상품 | Product | 위시에 담거나 주문하는 판매 대상 |
| 카테고리 | Category | 상품 분류 |
| 옵션 | Option | 상품의 선택지(색상·용량). 주문은 상품이 아니라 옵션을 가리킴. 테이블명은 options |
| 재고 | Stock | 옵션의 남은 수량. ⚠ 코드에서는 quantity라고 부름 |
| 주문 수량 | OrderQuantity | 한 번에 사는 개수. ⚠ 재고와 같은 이름 quantity 를 씀 |
| 상품 가격 | Price | 상품 1개 가격 |
| 주문 금액 | TotalPrice | 가격 × 수량. ⚠ 주문 코드에서는 price라고 부르고, DB에는 저장하지 않음 |
| 포인트 | Point | 주문 결제 수단. 오류 메시지에서는 "금액"이라고 부름 |
| 주문 | Order | 회원이 옵션을 산 기록. 카카오 메시지에서는 "선물"이라고 부름 |
| 선물 메시지 | GiftMessage | 주문 시 입력하는 글. ⚠ message가 카카오 알림 본문이라는 뜻으로도 쓰임 |
| 카카오 알림 | KakaoNotification | 주문 후 카카오톡 전송. 실제로는 주문자 본인에게 감 |
| 인증 토큰 | AccessToken | 서비스가 발급하는 JWT. ⚠ "token"이 카카오 토큰이라는 뜻으로도 쓰임 |
| 카카오 액세스 토큰 | KakaoAccessToken | 카카오 API 호출용 토큰 |
| 위시 | Wish | 회원이 찜한 상품 |

## 카카오 계정과 회원의 관계

현재 코드에서는 카카오 로그인 시 **카카오에서 받은 이메일로 서비스 회원 한 명을 찾거나 새로 만듭니다.** 이메일은 회원 테이블에서 유일하므로 같은 이메일로 두 회원이 매칭되는 일은 없습니다. 다만 이메일로만 가입한 회원도 있고, 서비스가 카카오 사용자 ID를 따로 저장하지 않기 때문에 **카카오 계정과 회원의 영구적인 1:1 관계는 보장되지 않습니다.**

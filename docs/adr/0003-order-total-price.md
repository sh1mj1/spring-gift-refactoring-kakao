# 0003. 주문 금액 계산을 Order에 둔다

- 상태: 채택

## 맥락

포인트를 차감할 때와 카카오 알림을 보낼 때 각각 상품 단가와 주문 수량을 곱했다. 두 호출부에서 계산하면 규칙이 바뀔 때 두 곳이 서로 달라질 수 있다.

## 결정

상품과 주문 수량을 알고 있는 `Order`에서 주문 금액을 계산한다. 주문 서비스는 포인트 차감에, 카카오 클라이언트는 금액 표시에 같은 계산 결과를 사용한다. 계산 시점의 상품 단가를 읽고 현재 정수 곱셈을 유지한다.

## 결과

- 금액 계산을 한 곳에서 변경하고 도메인 테스트로 검증할 수 있다.
- 계산 당시의 상품 단가를 참조하므로 가격이 바뀐 뒤 계산하면 주문 당시 금액과 달라질 수 있다.

# 0001. 주문 성공의 조건으로 카카오 발송 성공을 요구한다

- 상태: 채택

## 맥락

포인트 차감이 실패하면 재고만 줄 수 있었고, 발송 실패는 주문 성공에 영향을 주지 않았다. 카카오와의 계약에 따라 성공한 선물 주문에는 카카오 메시지를 보내야 한다.

## 결정

재고·포인트·주문 저장을 하나의 트랜잭션으로 처리하고 커밋 전에 카카오 메시지를 보낸다. 최초 발송이 실패하면 최대 5회 추가 시도한다. 토큰 누락 또는 최종 발송 실패는 403으로 응답하고 DB 변경을 롤백한다. 재고와 포인트 부족은 기존 500 응답을 유지하되 부분 반영을 방지한다.

## 결과

- 최종 발송 실패 시 재고, 포인트, 주문을 함께 되돌린다.
- 네트워크 호출과 재시도 동안 DB 트랜잭션이 열려 있다.
- 카카오가 수신한 뒤 응답이 유실되면 재시도로 중복 메시지가 갈 수 있다. 발송 성공 후 DB 커밋이 실패하면 메시지만 남을 수 있다.
- 재고·포인트 부족과 서버 오류는 HTTP 상태만으로 구분하기 어렵다.

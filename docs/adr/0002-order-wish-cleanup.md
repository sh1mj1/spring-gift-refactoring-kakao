# 0002. 주문과 구매자의 위시 정리를 함께 커밋한다

- 상태: 채택

## 맥락

주문 흐름에 위시 정리 단계가 있었지만 구매한 상품이 위시에 남았다. 주문과 별도로 정리하면 정리 실패에도 주문을 받을 수 있지만 구매한 상품이 계속 위시에 남을 수 있다.

## 결정

카카오 발송 전에 구매자의 해당 상품 위시를 주문 트랜잭션에서 삭제한다. 위시가 없으면 주문을 계속한다. 삭제가 실패하면 500을 반환하고 주문 전체를 롤백한다.

## 결과

- 성공한 주문과 해당 위시 삭제를 함께 반영한다. 카카오 발송이 최종 실패하면 위시도 복원된다.
- 위시 삭제 오류가 주문 가용성에 영향을 준다.
